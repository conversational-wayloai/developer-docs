Each tool is one Waylo API operation. Its name is the operation's id, and its input is the operation's path and query parameters, plus `body` for the request body. The [API reference](/api/reference) describes in full each one an API key can call.

A tool runs under the same rules as the API and the dashboard. It returns the operation's HTTP status and response:

```json
{ "status": 200, "body": { "user": { "name": "…", "email": "…" } } }
```

A call that runs past 30 seconds returns an error. For anything other than a read, the change may still happen: check before retrying.

## Which tools an agent sees

- **Signed in as a person:** every tool below. A tool still fails if your role doesn't allow it.
- **With an API key:** only the tools the key's [scopes](/api/scopes) allow. A tool that needs two scopes needs both. A workspace key sees no organization-level tools.

A tool the agent doesn't see answers `Unknown tool` and does nothing.

## Not available as tools

Operations an API key can call are tools, except creating, rotating and revoking keys, and uploading and downloading document files. A person who signed in also gets a few more: reads, and asking to switch organization. These are never tools:

- Signing in and out, and changes to your own account.
- Creating, rotating and revoking API keys.
- Adding, removing and changing members and their workspaces, and lifting a login lock.
- Editing the organization profile.
- Approving and disconnecting agents, and approving or denying an organization switch.
- Uploading and downloading document files.

## Switching organization

A person's agent acts in one organization. `getCurrentUser` lists every organization the person belongs to in `tenants`, with `current` marking the one the agent acts in. To move to another, the agent calls `requestTenantSwitch`:

```json
{ "body": { "tenantId": "…" } }
```

It returns `id`, `approvalUrl`, `organizationName` and `expiresAt`. The agent must show `approvalUrl` to the person: nothing changes until they open it and approve, and it expires after 10 minutes. It answers `404` for an organization the person doesn't belong to and `409` for the one the agent already acts in. See [Authorization](/mcp-server/authorization#switch-organization).

## All tools

**Role** is the least role a person needs. **API key** is the scope a key needs; "Not available" means only a person who signed in gets the tool.
