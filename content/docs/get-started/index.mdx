Waylo Voice is a voice agent platform: voice for any agent. You build an agent once, and callers reach it on a phone number or a talk button on a website. During a call the agent can use your tools, and every call leaves a transcript.

These docs cover the website part. A visitor clicks a button, speaks, and the agent answers out loud.

## The two parts

| Part | Runs in | What it does |
| --- | --- | --- |
| [Web SDK](/docs/web-sdk) (`@waylovoice/client`) | The visitor's browser | Joins the call, turns on the microphone, plays the agent's voice, reports status, captions and errors. |
| [Session endpoint](/docs/web-sdk/session-endpoint) | Your server | Checks your own login, then creates a call session with the Waylo API and your API key. |

The browser asks your server for a session. Your server asks the Waylo API. The browser then joins the call on the Waylo call server (WebRTC).

<Mermaid
  chart="

Your API key stays on your server. The page never sees it.
