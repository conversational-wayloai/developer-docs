A microphone or speaker. `label` is empty until the visitor allows the microphone.

## Properties

| Property | Modifier | Type | Description |
| ------ | ------ | ------ | ------ |
| <a id="property-deviceid"></a> `deviceId` | `readonly` | `string` | Pass it to `setMicrophoneDevice()` or `setSpeakerDevice()`. |
| <a id="property-label"></a> `label` | `readonly` | `string` | The name to show, such as "MacBook Pro Microphone". |
