Options for `new WayloVoice()`.

## Properties

| Property | Type | Description |
| ------ | ------ | ------ |
| <a id="property-agenttimeoutms"></a> `agentTimeoutMs?` | `number` | How long `start()` waits for the agent to be ready before failing with `AGENT_TIMEOUT`. Default 20 s. |
| <a id="property-headers"></a> `headers?` | [`SessionHeaders`](/docs/web-sdk/api/type-aliases/SessionHeaders) | Extra headers for the session endpoint, e.g. `Authorization`. Called once per `start()`; never logged. |
| <a id="property-sessionendpoint"></a> `sessionEndpoint` | `string` | Same-origin backend route that checks your login and returns the `POST /sessions/web` response. |
