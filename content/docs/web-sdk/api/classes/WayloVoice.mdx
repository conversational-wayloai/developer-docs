One single-use voice call. Safe to create on page load.

## Constructors

### Constructor

```ts
new WayloVoice(options): WayloVoice;
```

Throws `RangeError` for invalid options.

#### Parameters

| Parameter | Type |
| ------ | ------ |
| `options` | [`WayloVoiceOptions`](/docs/web-sdk/api/interfaces/WayloVoiceOptions) |

#### Returns

`WayloVoice`

## Methods

### getMicrophoneLevel()

```ts
getMicrophoneLevel(): number;
```

The visitor's live mic level, 0 to 1; 0 unless `microphone` is `on`. Cheap to poll every frame.

#### Returns

`number`

### resumeAudio()

```ts
resumeAudio(): Promise<void>;
```

Lets the browser play the agent's audio when `playback` is `blocked`. Call it from a click.

#### Returns

`Promise`\<`void`\>

***

### setMicrophoneDevice()

```ts
setMicrophoneDevice(deviceId): Promise<void>;
```

Uses this microphone, even before `start()`. Rejects with a mic error when it can't be opened;
the call then keeps a working microphone where it can.

#### Parameters

| Parameter | Type |
| ------ | ------ |
| `deviceId` | `string` |

#### Returns

`Promise`\<`void`\>

***

### setMuted()

```ts
setMuted(muted): Promise<void>;
```

Mutes or unmutes the mic, even before `start()`; unmuting can reject with a mic error.

#### Parameters

| Parameter | Type |
| ------ | ------ |
| `muted` | `boolean` |

#### Returns

`Promise`\<`void`\>
